# 结果如何判断

本库用于观察明确输入与参数下的行为，不以调用成功率排名。模型来自示意图重建，尺寸、隐藏面和拓扑不唯一，人工外观验收仍是独立步骤。

## 七道证据

1. 输入身份：文件哈希、有限面/边和共享拓扑来源。
2. 输入有效性与等价检查：内核有效性、体/片类型、边界、体积/面积及独立采样。仅体积相近不足以证明裁剪一致。
3. 目标选择：世界坐标曲线匹配；不同内核的边编号不可直接复用。多义匹配必须停止。
4. 调用行为：参数、原始状态、超时/崩溃阶段；失败候选保留。
5. 几何质量：类型/闭合、非目标区域、截面/半径、实际目标是否被替换；未测项目写未验证。
6. 持久化与连续性：原生文件读回；G0/G1/G2 需正确对应接头，不能用任意两面法向或 `continuity=2` 代替实测。
7. 原图协议与人工验收：大小圆角是否触发障碍、指定封口是否生效、参数含义是否一致、外观是否还原。

前一道通过不自动通过后一道。G2 接头可连续但整体仍可能过冲或自交。API 返回成功也可能保留原锐边、返回开片或空结果。

## 两种输入表示

OCCT 从固定 BREP 读取；SMLib 从同源有限 NURBS 与共享拓扑 JSON 重建。显式交换不拼接、愈合、加厚或删除失败面。两者几何来源相同，解析/样条表示和公差处理仍不同，结果差异不能无条件归因于内核算法。

## 两种构造路线

`native_edge_fillet` / `native_surface_blend` 表示原生调用。几何裁剪、布尔、补面或插值完成的组合构造应使用单独 protocol ID，不能当作原生功能结果。无成对证据时页面显示缺项，不能拿不同半径/模型的图凑齐三栏。

## 历史与新运行

公开网格是实际运行导出的可视化采样，不是精确模型本身；调试需重跑并检查原生产物。历史记录标出来源与缺口，缺少精确脚本/依赖的记录不宣称可精确复现。当前统一入口主要覆盖普通边圆角，特殊参数协议单列。
