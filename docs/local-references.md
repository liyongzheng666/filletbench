# 浏览器本地参考图

公开仓库和网站不分发参考 PDF、截图或包含原图的合成图片。你选择的 PDF/图片只在当前浏览器解析并保存在 IndexedDB，页面没有上传接口。PDF 可按物理页号定位、框选、缩放与平移；图片按案例隔离。

案例建议区域仅在完整文件 SHA256 匹配时应用。其他版次或其他 PDF 显示完整页，需自行核对。原模型的几何哈希不等于 PDF 文件哈希。

## 坐标约定

旧参考 PNG 对应 PDF MediaBox；PDF.js 渲染的是 CropBox。两者有边距差异。本库的 `reference.suggested_crop` 已转换为 PDF.js CropBox 内、从左上角起的归一化坐标，不能直接复制旧 PNG 的归一化区域。

每项保存 `source_media_box`、`pdf_crop_box` 和 `source_media_box_crop`，供定位坐标来源；这些是位置元数据，不含 PDF 图像。来源 PDF 的 34 个物理页已核对框尺寸。建议区域仍允许人工调整，某些页面包含多个相关子图。

已保存的用户裁切会保留。需要恢复新建议时，在参考设置中选择“使用建议区域”，再应用到当前案例；清除本地参考不会删除磁盘原文件。
